   - Stub a React Context (AuthContext) that exposes `{ role: 'owner'|'staff', tenantId }`.

2. **One central config**

6. **Continuous test suite generation**  
   - After generating or updating any component or hook, automatically generate or update its corresponding test file under `__tests__`.

   - Ensure your commit hook runs all tests.

7. **CI integration**  
   - Add a `.replit` test command or GitHub Actions workflow to run `npm test && npm run lint` on every push.  
   - Fail the build if anything is broken.

8. **Never deviate**  
   - If any step fails or tests break, fix it before moving on.  
   - No partial commits. Every change must pass the full test suite and lint before it’s checked in.
