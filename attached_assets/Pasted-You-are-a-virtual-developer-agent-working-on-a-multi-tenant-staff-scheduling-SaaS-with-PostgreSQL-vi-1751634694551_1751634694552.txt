You are a virtual developer agent working on a multi-tenant staff-scheduling SaaS with PostgreSQL via Drizzle ORM and a Node.js backend that uses cron jobs.

**Task: Early Check-Out & Missing Check-Out Detection Jobs**  
**Goal:** Automatically flag shifts where staff left early or forgot to clock out, by creating a daily cron job.

**Instructions:**  
1. **Create a new job file**  
   - Path: `src/jobs/checkOutDetection.ts`  
   - Export a function `runCheckOutDetection()`.

2. **Schedule the job**  
   - In your existing cron setup (e.g. `src/cron.ts`), import and schedule `runCheckOutDetection` to run every day at 23:59.

3. **Inside `runCheckOutDetection()`**  
   - Load the current tenant policies for buffer/grace periods.  
   - Query `shifts` joined to `time_entries` for each shift where:  
     - `scheduledEnd` + `policy.graceMinutes` < now **AND** `actualOut` IS NULL  
       → treat as **missing check-out**.  
     - `actualOut` IS NOT NULL **AND** `actualOut` < `scheduledEnd` – `policy.earlyLeaveBuffer`  
       → treat as **early check-out**.  
   - For each flagged entry, insert into `escaltions` (or your chosen table) a record with:  
     - `shiftId`, `type` (‘missing_check_out’ or ‘early_check_out’), `detectedAt`: now.  
   - Log a summary: “X missing check-outs, Y early check-outs detected.”

4. **Drizzle snippet example**  
   ```ts
   const results = await db
     .select({
       shiftId: shifts.id,
       actualOut: timeEntries.actualOut,
       scheduledEnd: shifts.scheduledEnd
     })
     .from(shifts)
     .leftJoin(timeEntries, eq(timeEntries.shiftId, shifts.id))
     .where(
       or(
         and(
           lt(addMinutes(shifts.scheduledEnd, policy.grace), now()),
           isNull(timeEntries.actualOut)
         ),
         and(
           lt(timeEntries.actualOut, subMinutes(shifts.scheduledEnd, policy.earlyLeaveBuffer)),
           not(isNull(timeEntries.actualOut))
         )
       )
     );
