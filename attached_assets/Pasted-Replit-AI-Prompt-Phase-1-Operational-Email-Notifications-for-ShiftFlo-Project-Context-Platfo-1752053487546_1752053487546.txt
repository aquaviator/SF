Replit AI Prompt — Phase 1: Operational Email Notifications for ShiftFlo
🗂️ Project Context:
Platform: ShiftFlo (multi-tenant workforce scheduling system)

Stack: TypeScript, Node.js (Express), Firestore + SQL hybrid, Tailwind/DaisyUI frontend

Email system: Nodemailer (Gmail SMTP) already working

Existing email functions: Activation, password reset, staff invites

Database: Shifts stored in shifts table/collection with status, assignmentType, assignedTo, etc.

📌 Goal:
Implement the first phase of shift-related operational email notifications. Add new server-side email functions using the existing Nodemailer infrastructure, triggered by events in the shift lifecycle.

✅ Phase 1 Requirements
✉️ 1. sendShiftAssignmentEmail
Trigger: A shift is created or updated with status = assigned and assignedTo = <staff_id>

Content: HTML email notifying the staff of a new shift assignment, including:

Shift date/time

Position

Option to accept/decline (include link to system)

Email Template Name: shift-assigned.hbs

Recipient: staff.email

✉️ 2. sendShiftReminderEmail
Trigger: Scheduled task (e.g., via cron or Firestore scheduled function)

Timing: 2–4 hours before a shift starts where status = confirmed

Content:

Reminder of upcoming shift

Start time, role, and location

Email Template: shift-reminder.hbs

✉️ 3. sendSwapRequestEmail
Trigger: Staff initiates a swap request (POST /api/swaps)

Recipients:

Staff member involved in the swap

Owner (for escalated swaps)

Email Template: swap-request.hbs

Includes:

Reason

Proposed shift details

Link to approve/decline

✉️ 4. sendHolidayRequestEmail
Trigger: Time-off request submitted or status changes

Recipients:

Owner on new request

Staff on approval/rejection

Template(s):

holiday-request.hbs

holiday-status.hbs

✉️ 5. sendEmergencyShiftAlert
Trigger: Shift is cancelled or no-show within 2 hours

Recipients: All eligible staff for the role

Template: emergency-alert.hbs

Includes:

Shift time and urgency message

CTA to claim shift immediately
