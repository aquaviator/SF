You are a virtual developer agent working on a multi-tenant staff-scheduling SaaS built with PostgreSQL via Drizzle ORM, Node.js/Express back end, and a React + Tailwind front end.

**Task: Build Business Registration Flow**  
**Goal:** Let a new company (“tenant”) sign up by entering their business profile, owner user details, and selecting a seat-based plan. On success, create the tenant, business_profiles record, owner user, and initial subscription; then log them in.

**Instructions:**

1. **Back-End – API Route**  
   - **Route:** `POST /api/register-business`  
   - **Request Body:**  
     ```json
     {
       "business": {
         "name": "Acme Inc",
         "subdomain": "acme",
         "businessType": "Retail",
         "address": "...",
         "phone": "...",
         "email": "...",
         "website": "...",
         "logoUrl": "...",
         "description": "..."
       },
       "owner": {
         "firstName": "Alice",
         "lastName": "Johnson",
         "email": "alice@acme.com",
         "username": "alicej",
         "password": "••••••"
       },
       "planId": 2
     }
     ```
   - **Behavior:**  
     1. Create a new `tenants` record.  
     2. Insert into `business_profiles` using `tenant.id` and `business` fields.  
     3. Hash `owner.password`, insert a new `users` record with `tenant_id`, `role='owner'`, `is_active=true`.  
     4. Lookup `seat_pricing` by `planId`, then insert into `subscriptions`:
        - `tenant_id`, `plan_id`, `status='active'`, `start_date=now()`, `end_date=now() + 30 days`,
        - `seats_included`, `price_per_seat`, `monthly_total = seats_included * price_per_seat`,
        - leave Stripe fields null.
     5. Sign a JWT containing `{ userId, tenantId, role }`, set in an HttpOnly cookie.  
     6. Return JSON: `{ user: { id, firstName, role }, tenant: { id, name, subdomain } }`.

2. **Back-End – Drizzle Schema**  
   - Ensure `tenants`, `business_profiles`, `users`, `subscriptions`, and `seat_pricing` tables exist with all columns and FKs as specified.  
   - Your migration for `tenants` should match:
     ```ts
     export const tenants = pgTable('tenants', {
       id: serial('id').primaryKey(),
       name: text('name').notNull(),
       subdomain: varchar('subdomain').notNull().unique(),
       createdAt: timestamp('created_at').notNull().defaultNow(),
     });
     ```

3. **Front-End – Registration Page**  
   - **File:** `client/src/pages/RegisterBusiness.jsx`  
   - **UI:**  
     - Section “Business Info”: inputs for name, subdomain, businessType (dropdown), address, phone, email, website, logo upload (URL or file upload).  
     - Section “Owner Info”: inputs for firstName, lastName, email, username, password.  
     - Section “Plan Selection”: fetch `/api/seat-pricing`, render radio/select of `tierName` with `pricePerSeat` and seat range.  
     - “Sign Up” button disabled until form valid.  
   - **On Submit:** POST to `/api/register-business` with payload above.  
   - **On Success:** redirect to `/dashboard` (user is logged in via cookie).

4. **Front-End – Auth Hook**  
   - On app load, check for valid JWT via `GET /api/me`; if present, store user/tenant context.

**Output:**  
Reply **only** with the code diffs and new files your agent would apply for:  
- `src/routes/register-business.ts` (Express route)  
- Any needed Drizzle migration (if missing)  
- `client/src/pages/RegisterBusiness.jsx`  
- Example of setting the JWT cookie in the response
