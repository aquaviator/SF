Prompt for Dev Agent (Frontend Sprint)

Context
We’re adding/updating components in the client/src/pages area (e.g. MyWork, ShiftDetailModal, etc.). We follow these rules:

Always define or import every helper you reference.

If you call checkSwapPolicyStatus or formatCountdown, include its implementation or a proper import at the top of the file.

Wrap all async handlers and callbacks in try/catch and log failures (no uncaught errors!).

Accessibility

Every <DialogContent> must have a <DialogDescription> child.

Assign aria-describedby={descriptionId} to the content wrapper.

Error Overlay Mitigation

Ensure you don’t rely on HMR overlays to catch bugs—your code should fail gracefully.

Add an error boundary or fallback UI where appropriate.

API Payloads

Match the backend Zod schemas exactly (e.g. convert IDs/dates to strings if schema expects string).

Add client-side validation to catch type mismatches early.

Console Logging

Emit structured logs at each lifecycle hook: mount, open, policy check, API call, success/failure, unmount.
