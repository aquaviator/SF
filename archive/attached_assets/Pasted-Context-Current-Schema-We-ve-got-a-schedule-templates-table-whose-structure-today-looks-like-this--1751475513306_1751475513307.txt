2. API Endpoints
GET /api/schedule-templates?tenantId=… → include slots in the response.

POST /api/schedule-templates → accept payload:

json

  ]
}
PUT /api/schedule-templates/:id → update slots plus other fields.

POST /api/schedule-templates/:id/use

Behavior:

For each slot entry:

If staffIds non-empty, create that many assigned shift records.

Let openCount = quantity − staffIds.length; create that many open_opportunity shifts.

Return a summary:
