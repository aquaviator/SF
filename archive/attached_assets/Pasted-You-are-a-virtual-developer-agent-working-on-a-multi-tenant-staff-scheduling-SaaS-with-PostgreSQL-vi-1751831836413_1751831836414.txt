1. **Remove Old Pricing Plans**

2. **Expose Seat Pricing API**

     - **GET** `/api/admin/seat-pricing` → returns the single active row (or list if you support multiple tiers).  
     - **PATCH** `/api/admin/seat-pricing/:id` → update `price_per_seat` (and optional `min_seats`, `max_seats`, `features`).

3. **Admin UI – Seat Pricing Page**  
   - **Sidebar Link:** add “Seat Pricing” under Financial.  
   - Create `client/src/pages/SeatPricing.jsx`:
     ```jsx
     import { useState, useEffect } from 'react';
     import { Input, Button } from '@/components/ui';
     
     export default function SeatPricing() {
       const [plan, setPlan] = useState(null);
       const [price, setPrice] = useState('');
       useEffect(() => {
         fetch('/api/admin/seat-pricing', { credentials: 'include' })
           .then(r => r.json()).then(data => {
             setPlan(data);
             setPrice((data.price_per_seat / 100).toFixed(2));
           });
       }, []);
       const save = () => {
         fetch(`/api/admin/seat-pricing/${plan.id}`, {
           method: 'PATCH',
           credentials: 'include',
           headers: { 'Content-Type':'application/json' },
           body: JSON.stringify({ price_per_seat: Math.round(parseFloat(price)*100) })
         }).then(() => alert('Seat price updated'));
       };
       return plan && (
         <div className="p-6">
           <h2 className="text-xl font-semibold">Seat Pricing</h2>
           <div className="mt-4">
             <label>Price per seat (£)</label>
             <Input value={price} onChange={e => setPrice(e.target.value)} type="number" step="0.01" />
           </div>
           <Button className="mt-4" onClick={save}>Save</Button>
         </div>
       );
     }
     ```
   - Add route in your Admin router:  
     ```jsx
     <Route path="/admin/seat-pricing" element={<SeatPricing />} />
     ```
