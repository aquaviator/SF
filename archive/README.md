# Archive Folder

This folder contains development files, documentation, and test scripts that were moved during project cleanup.

## Contents

### `/documentation/`
- All markdown documentation files
- Analysis reports and project documentation
- Sprint reports and architectural analysis

### `/test-files/`
- Unit test files (*.test.ts, *.test.tsx)
- Integration test scripts
- Authentication and API test scripts
- Development debugging scripts

### `/development-scripts/`
- Database export scripts
- GitHub export automation
- Sample data generation scripts
- Deployment configuration files

### `/temp-files/`
- Temporary cookie and session files
- Login response files
- Debug output files

### `/attached_assets/`
- User-uploaded assets and images
- Temporary files from development

### `/docs/`
- Additional documentation files

## Purpose

These files were archived to keep the main project directory clean and focused on production code while preserving all development artifacts for reference.
